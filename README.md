
##### Android App:
To build the android app:

On android studios, open the android folder
In this case it is:
`Quiz2\android`

Then sync gradle files, and then run the app


##### Web App:
To build the web app

(do note to install latest as well if you have not)

You need to .\emsdk activate latest in your emsdk folder

Then travel to the `Quiz2` folder and open a cmd.
Type `build_web.bat` to build it.
Follow the instructions:
`cd web`
`python -m http.server 8080`

(please have python preinstalled in order to run this)

to view the website head over to
`http://localhost:8080/` to view it


##### Desktop / Windows App:
Go to `Quiz2` folder and open a cmd
then type `script_build_and_run.bat`
The program will eventually load up and appear on your screen.
